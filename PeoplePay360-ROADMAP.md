# PeoplePay360 — Future Roadmap

With more development time we would prioritize:

1. **Automated demo seed script** — one-click company, employees, contracts, schedules, leave allocations, and a sample payrun.
2. **Self-service mobile polish** — tighten the Vue/Ionic PWA for attendance + time-off only (no payroll for employees).
3. **Contract amendment workflow** — versioned contract changes with approval and automatic SSA sync.
4. **Advanced payroll validations** — rule-level simulation before Compute, and richer payslip category totals (Basic / Allowances / Gross / Net).
5. **Edge security layer** — Cloudflare + Nginx rate limits + Prometheus/Grafana observability for production deployment.
